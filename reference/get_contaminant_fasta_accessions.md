# Extract the contaminants protein accessions from a contaminants fasta file

Extract the contaminants protein accessions from a contaminants fasta
file

## Usage

``` r
get_contaminant_fasta_accessions(cont_fasta_inf)
```

## Arguments

- cont_fasta_inf:

  `character` Filepath to the contaminants fasta

## Value

Returns a `list` of contaminant IDs
