# Experimental design for `psm_tmt_clock`

A `data.frame` giving the Condition (`Control`/`Mutant`) and Replicate
for each sample in
[`psm_tmt_clock`](https://lmb-mass-spec-compbio.github.io/biomasslmb/reference/psm_tmt_clock.md),
with rownames matching the quantification column names.

## Usage

``` r
tmt_clock_design
```

## Format

An object of class `data.frame` with 12 rows and 4 columns.
