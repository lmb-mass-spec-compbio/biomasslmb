# PSM-level PD output for the total fraction matching `psm_tmt_phospho`

Proteome Discoverer PSM-level output for the total (non-enriched)
fraction of the experiment described in
[`psm_tmt_phospho`](https://lmb-mass-spec-compbio.github.io/biomasslmb/reference/psm_tmt_phospho.md),
acquired from the same labelled pool and so sharing its experimental
design. Used to normalise the enriched fraction and to express site
abundance relative to protein abundance.

## Usage

``` r
psm_tmt_phospho_total
```

## Format

An object of class `data.frame` with 17045 rows and 77 columns.
