# Experimental design for `psm_tmt_per2_mq`

A `data.frame` giving the Condition (`IP`/`Control`) and Replicate for
each sample in
[`psm_tmt_per2_mq`](https://lmb-mass-spec-compbio.github.io/biomasslmb/reference/psm_tmt_per2_mq.md),
with rownames matching the quantification column names.

## Usage

``` r
tmt_per2_mq_design
```

## Format

An object of class `data.frame` with 12 rows and 3 columns.
