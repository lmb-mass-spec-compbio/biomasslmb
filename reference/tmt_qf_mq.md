# TMT data (MaxQuant input)

`QFeatures` object containing the MaxQuant TMT IP-vs-control data
([`psm_tmt_per2_mq`](https://lmb-mass-spec-compbio.github.io/biomasslmb/reference/psm_tmt_per2_mq.md))
processed through PSM filtering and `robustSummary` summarisation to
protein level, as produced in Part A of the
`Enrichment designs: IP, BioID and TurboID` vignette.

## Usage

``` r
tmt_qf_mq
```

## Format

An object of class `QFeatures` of length 5.
